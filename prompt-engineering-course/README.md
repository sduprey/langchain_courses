# LangChain / LangGraph Course Notebooks

These are the lesson notebooks for four DeepLearning.AI short courses built with LangChain. They couldn't be pulled directly from learn.deeplearning.ai since the notebooks live inside a logged-in, interactive coding environment there — these are community-maintained mirrors of the same lesson content, sourced from public GitHub repos.

- **01-AI-Agents-in-LangGraph** (4 notebooks) — taught by Harrison Chase (LangChain) & Rotem Weiss (Tavily). Source: ksm26/AI-Agents-in-LangGraph
- **02-LangChain-for-LLM-Application-Development** (6 notebooks) — taught by Harrison Chase & Andrew Ng. Source: ksm26/LangChain-for-LLM-Application-Development
- **03-Functions-Tools-and-Agents-with-LangChain** (6 notebooks) — taught by Harrison Chase. Source: ksm26/Functions-Tools-and-Agents-with-LangChain
- **04-Long-Term-Agentic-Memory-with-LangGraph** (4 notebooks) — taught by Harrison Chase & Andrew Ng. Source: sftSalman/Long-Term-Agentic-Memory-With-LangGraph

Notes:
- Some notebooks reference helper/util files or local data that lived in the original DeepLearning.AI workspace and aren't included here.
- You'll need your own API keys (OpenAI, Tavily, etc.) to run the cells — check each notebook for `load_dotenv()` calls or `import os` blocks near the top.
- For the official, graded, video-paired experience, the courses remain free to take at learn.deeplearning.ai.
